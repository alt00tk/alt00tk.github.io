# 承認済みプロトタイプの見た目を実装する

## 問題

記事ページの基本動作ができても、承認済みプロトタイプの幅、文字、余白、ヘッダー、フッターを再現しなければ、決定済みのブログデザインにならない。

## 意図

引継ぎ資料に同梱された試作HTMLを見た目の基準として、一覧、詳細、ページ送りの共通スタイルとレスポンシブ表示を実装する。

## 受け入れ条件

- [x] .local/blog-mvp-codex-handoff.tar.gz に含まれる blog-mvp-interactive-prototype-v4.html と引継ぎ資料の意図に沿い、最小限で読みやすく落ち着いた表示になる。
- [x] 背景は #f7f7f3、文字は #1f2421、補助文字は #7a827d、アクセントは #556a5d とする。区切り線は文字色の12%を透明色へ混ぜる。サイト最大幅は900px、記事最大幅は825pxとする。
- [x] Zen Maru Gothicを主フォントとし、指定された400・500・700のウェイトを使う。基準文字サイズは 1rem、行高は 1.95、字間は 0.015em とする。
- [x] ヘッダーは左寄せの notes のみを表示して / へリンクし、下部に区切り線を置く。
- [x] フッターは上部に区切り線を置き、「© 2026 notes」を表示する。短いページでは画面下部に位置し、長いページでは本文の後に続く。固定配置を使わない。
- [x] 記事一覧はデスクトップで日付列と記事内容列を使い、モバイルでは日付をタイトル・descriptionの上に積む。記事ごとの区切り線は置かない。一覧・詳細の日付文字サイズは本文と同じ 1rem とする。
- [x] 記事詳細は日付、タイトル、description、区切り線、本文の順にし、本文の後に十分な余白を設けて ← Articles を置く。戻るリンク専用の区切り線を追加しない。
- [x] ページ送りは「Newer / 現在位置 / Older」の3列構成を保ち、番号リンク列やカード装飾を追加しない。
- [x] 幅640px前後を境に、小画面では横余白を減らし、承認済みのモバイル配置になる。実装結果を広い画面と小さい画面で確認する。
- [x] カード、影、グラデーション、イラスト、バッジ、チップ、装飾アイコン、余分なナビゲーションを追加しない。

## 対象外

- Issue 002・003で扱う記事データ処理、URL、ページ送り条件の変更
- Aboutページなど新しい画面・機能の追加
- favicon（Astroの初期生成で必須の場合を除く）、独自404、分析、OGP画像生成
- JavaScriptを使ったレイアウトや遷移

## 品質境界

一覧、詳細、ページ送りを共通の静的ページ構造上で一貫して表示し、プロトタイプの余白と読みやすさを保つ。追加の装飾や画面は作らない。

## 実装メモ

- ビジュアル参照の正本は .local/blog-mvp-codex-handoff.tar.gz 内の blog-mvp-codex-handoff/blog-mvp-interactive-prototype-v4.html。引継ぎ資料の明示的な上書きがある箇所は資料を優先する。
- ページ全体を縦方向のflex構造にし、最小高さを 100dvh、本文領域を伸長可能にする。
- 記事タイトルは clamp(1.45rem, 3vw, 1.8rem)、行高は 1.65、ウェイトは700を基準にする。

## 設計判断

- 決定: ページ全体の背景、色、文字、ヘッダー、フッターを`BaseLayout.astro`と共通の`global.css`へまとめた。`.site`を`min-height: 100dvh`の縦flexにし、本文を伸長させて短いページでもフッターを下端へ置く。各ページへ枠組みを重ねる案や固定フッターは、一覧と詳細の一貫性および長文で自然に続く条件を満たさないため採用しない。
- 決定: 一覧は日付列108pxと記事内容列のgridにし、640px以下では一列へ切り替えた。ページ送りも共通CSSの3列gridとし、現在位置を中央に保つ。画面ごとに別の配置を作らず、プロトタイプにあるdesktop/mobileの関係と固定された操作列を保つためである。
- 決定: Astroが生成するコードブロックの濃色テーマは、淡い背景と少ない色数というサイトの意図に合わないため、背景を本文色の5%を混ぜた色へ、コード文字を本文色へ揃えた。角丸や枠を追加せず、横長コードは横スクロールにする。

## 完了記録

- 変更: 共通layoutにnotesヘッダー、Google FontsのZen Maru Gothic（400・500・700）、フッターを加え、flexレイアウトと共通CSSで幅・色・文字・区切り線を実装した。一覧はdesktopの日付列とmobileの日付積み上げ、3列ページ送りを適用した。詳細は825px幅、メタ情報の区切り、本文の余白、読了後の← Articlesを整えた。コードブロックはサイトの淡い配色に揃えた。
- 検証: `npm ci --offline --cache=/tmp/blog-001-npm-cache`と`npm run build`を実行した。一時的な11件の記事から一覧、詳細、2ページ目を含む13静的ページを生成し、Chromium Headless Shellで一覧を1440×1600・390×2100、詳細を1440×1200・390×1800で表示した。広い画面の日付列、小さい画面の日付積み上げ、本文幅、戻りリンクの余白、短いページのフッター位置を確認した。スクリーンショット用の一時ページからはネットワーク制限のため外部Google Fontsリンクを除いており、画像ではローカルフォールバック書体を使用した。画像・記事を除いた後の`npm run build`も成功した（記事未登録に関する既存の警告あり）。`git diff --check`を実行した。
- レビュー観点: 独立レビューは未実施。レビュー時は640px境界の一覧配置、Google Fonts読込と配色、長い記事でのフッター配置、本文後のナビゲーション余白を確認する。

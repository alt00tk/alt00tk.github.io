# 記事のRSSフィードを公開する

## 問題

サイトには記事の一覧とページ送りがあるが、新しい記事の公開を継続的に受け取るためのRSSフィードがない。

## 意図

記事のタイトル、概要、公開日時を含むRSSフィードを静的に公開し、読者が更新を購読できるようにする。

## 受け入れ条件

- [x] `/rss.xml` から有効なRSSフィードを取得できる。
- [x] フィードにサイト情報と、公開中の全記事のタイトル、記事URL、概要、公開日時が含まれる。
- [x] 記事は公開日時の新しい順に並び、ページ送りの有無にかかわらず各記事が一度ずつ含まれる。
- [x] 記事URLはサイトの正規の絶対URLを指し、XMLの予約文字を含む値も正しく読める。
- [x] サイトのページからフィードを発見でき、記事がない場合もフィードが有効な形で出力される。
- [x] 記事の追加・更新に伴ってフィードが自動更新され、別の手動リストを保守しない。

## 対象外

- RSS本文への記事全文掲載
- メール通知、購読者管理、外部配信サービス
- Atomなど別形式のフィード

## 品質境界

静的ビルド時点で公開中の記事とメタデータが正しくフィードへ反映され、読者が標準的なRSSリーダーから購読できることを対象とする。記事本文のHTML変換や購読者データの管理は含めない。

## 実装メモ

- `title`、`description`、`publishedAt` は既存の必須メタデータを使える。
- サイトの絶対URLは `astro.config.mjs` の `site` 設定を基準にする。
- 概要のみを配信し、フィードの各記事URLは既存のHTML記事ページを指す。

## 設計判断

- `getCollection("blog")` の全件を既存の `sortArticlesByPublishedAt` で並べ、静的endpointから `/rss.xml` を生成する。ページ分割を通さず、HTML記事と同じ公開対象を一度ずつ列挙する。公開日時の時差とサブミリ秒を含む並び順は既存処理で確定してから、RSSの日時へ変換する。
- RSS 2.0の生成にはAstro公式の `@astrojs/rss` 4.0.19を固定バージョンで追加し、XMLのエスケープ、公開日時のUTC表記、記事URLと同じguidの生成を委ねる。XMLを独自に連結する案より、標準的なRSSを出力する責務を公式生成器へ集約できる。サイト名・紹介は既存表示に合わせ、言語を `ja` とし、本文全文は配信しない。参考: [Astro公式RSSガイド](https://docs.astro.build/en/recipes/rss/)。
- 記事URLは既存canonicalと同じ `/articles/{id}/` とし、`astro.config.mjs` の `site` を基準に絶対URL化する。`site` が未設定ならビルドを失敗させる。共通レイアウトのheadへRSS自動検出用の `link`、ヘッダーへアクセシブル名を持つRSSアイコンの通常アンカーを追加し、全ページからJavaScriptなしで発見できるようにする。

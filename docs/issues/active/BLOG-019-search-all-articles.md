# 記事一覧をタイトル・説明文で全記事検索できるようにする

## 問題

記事一覧にはタイトルと説明文が表示されるが、キーワードで絞り込む操作はない。現在は公開記事が8件で1ページに収まるものの、一覧は1ページ10件で、記事が増えるとページをまたいで探す必要がある。

## 意図

記事一覧から、タイトルまたは説明文を手掛かりに全公開記事を検索できるようにする。

## 受け入れ条件

- [x] トップとページ送り先の記事一覧に検索操作があり、入力した文字列がタイトルまたは説明文に含まれる公開記事を表示する。
- [x] 検索対象はページ分割に依存せず、全公開記事を含む。
- [x] 入力に応じて該当記事と件数を表示し、該当記事がない場合は0件であることが分かる。入力を消すと通常の記事一覧へ戻る。
- [x] 検索結果の記事タイトルから、既存の通常リンクで記事詳細へ移動できる。
- [x] 検索入力と結果の操作・移動をキーボードで行える。
- [x] JavaScriptが利用できない場合も、検索前の既存記事一覧とページ送りで記事を閲覧できる。

## 対象外

- 記事本文の全文検索
- 外部検索サービスや検索用サーバーの導入
- 記事データ、公開順、既存ページ送り件数の変更

## 品質境界

検索対象はビルド時点の全公開記事とし、ページ分割後も記事を取りこぼさず検索できることを対象とする。検索結果の移動は既存の記事詳細URLを使い、JavaScriptが利用できない場合の一覧閲覧を保つ。

## 実装メモ

- 対象箇所は `src/components/ArticleList.astro`、`src/pages/index.astro`、`src/pages/articles/page/[page].astro`。
- 起案時から記事が増え、実装時点の公開記事は10件だった。
  実記事に加え、21件で3ページになる隔離した一時環境でページをまたぐ検索を確認した。

## 設計判断

- 決定: 一覧の各ルートから公開順に並べた全公開記事を共有コンポーネントへ渡し、既存の10件単位の切り出しで初期表示する記事を決める。
  各記事は通常リンク付きのHTMLとして一度だけ出力し、現在ページに属さない記事にはサーバー側で `hidden` を付ける。
  検索用JSONと結果描画を別に持つ案に比べ、タイトル、説明文、日付、リンクの出力を共通化でき、JavaScriptが動かなくても元ページの表示を保てるため採用した。
- 決定: 入力欄はイベント登録と初回更新を完了した後に表示し、入力文字列とタイトルまたは説明文の部分一致で全記事を絞り込む。
  英字は小文字にそろえ、入力を空にすると元ページの表示とページ送りを復元する。
  検索中は全結果と件数を表示してページ送りを隠し、0件も明示する。
- 決定: 結果の更新は既存HTMLの `hidden` の切り替えに限定し、記事への移動は既存の通常リンクを使う。
  検索欄にラベルと結果一覧への関連付けを置き、件数を `role="status"` で示す。
  `display: grid` は非表示でない記事とページ送りだけに適用し、既存の画面幅に応じた配置規則を保つ。

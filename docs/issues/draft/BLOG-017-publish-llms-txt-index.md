# 全記事を案内するllms.txtを生成する

## 問題

トップページの記事一覧はページ送りで分かれており、AIやテキスト処理ツールがサイトの概要と全記事のMarkdown原文を一度に発見できる機械可読な案内がない。

## 意図

サイト紹介と公開中の全記事への案内を `/llms.txt` に自動生成し、トップページから到達できるようにする。

## 受け入れ条件

- [ ] `/llms.txt` から直接取得できるUTF-8テキストが生成され、HTMLページを返さない。
- [ ] ファイルにはサイトの短い紹介と、公開中の全記事それぞれのタイトル、概要、Markdown原文への絶対URLが含まれる。
- [ ] 記事の追加・削除・タイトル・概要の変更が、別の手動管理リストなしに出力へ反映される。
- [ ] Markdown URLは各記事の原文配信先と一致し、ページ送りの全ページを通じて公開記事が一度ずつ列挙される。
- [ ] トップページに `/llms.txt` への通常リンクがあり、JavaScriptなしで移動できる。
- [ ] 公開記事がない場合も有効な案内ファイルが生成される。

## 対象外

- `/llms.md` や他の別名ファイルの生成
- 記事本文全文を一つのファイルへ連結すること
- AI API、要約生成、非公開記事の列挙

## 品質境界

`/llms.txt` の記事一覧とリンク先が現在の公開記事データに一致し、各原文を直接取得できることを対象とする。原文配信はBLOG-014で成立させ、サイト紹介と記事概要以外の情報を追加しない。

## 実装メモ

- 参考形式に合わせ、Markdown記法を使ったテキストを `/llms.txt` に出力する。
- 記事の情報と並び順は既存コレクションから取得し、公開記事全件を対象とする。
- BLOG-014が定めるMarkdown原文URLを絶対URL化して列挙する。

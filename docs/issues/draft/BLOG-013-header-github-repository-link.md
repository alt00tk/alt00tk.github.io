# ヘッダーにGitHubリポジトリへのリンクを追加する

## 問題

サイトのヘッダーには「notes」へのリンクだけがあり、記事の原稿やサイトの実装を管理する公開GitHubリポジトリへ、サイトから移動する手段がない。

## 意図

すべてのページのヘッダーから、このサイトのGitHubリポジトリへ移動できるようにする。

## 受け入れ条件

- [ ] 生成された全ページのヘッダーに `https://github.com/alt00tk/alt00tk.github.io` へのリンクがある。
- [ ] リンクはアイコンで示され、支援技術から目的が分かり、キーボードでも操作できる。
- [ ] デスクトップと狭い画面の両方で、サイト名リンクや本文の閲覧を妨げない。
- [ ] 外部リンクの開き方が明確で、別タブで開く場合は安全な関係属性を持つ。

## 対象外

- GitHubユーザープロフィール、他のSNSや連絡先へのリンク
- ヘッダー全体の再設計

## 品質境界

共通レイアウトを使うトップ、記事一覧、記事詳細のすべてで、同一の公開リポジトリへ移動できることを対象とする。既存のサイト内リンク、ページレイアウト、キーボード操作を損なわない。

## 実装メモ

- 共通ヘッダーは `src/layouts/BaseLayout.astro` にある。
- 記事本文の外部リンク処理は本文内だけを対象にするため、ヘッダーリンクの開き方は独立して確認する。

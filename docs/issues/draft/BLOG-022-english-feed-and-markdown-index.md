# 英語記事をRSSとllms.txtから参照できるようにする

## 問題

現行RSSとllms.txtは日本語記事のみを列挙する。英語ページがあっても英語の購読・Markdown案内がない。

## 意図

英語読者と外部ツールが英語記事を購読・参照できるようにする。

## 受け入れ条件

- [ ] 既存/rss.xmlの日本語記事とURLを維持し、/en/rss.xmlには英語記事のみを英語のタイトル・概要・言語情報とHTML URLで出力する。
- [ ] /llms.txtに日本語・英語のMarkdown URLを言語別に案内し、英語側のヘッダーからも利用できる。未生成のURLを列挙しない。
- [ ] 英語ページのRSSリンクとalternate情報は/en/rss.xmlを指し、日本語ページの購読先は維持する。
- [ ] 英語0件でもRSSと案内は有効な空一覧になり、ビルドが成功する。日英同名の記事が混線・重複しない。
- [ ] 依存Issueだけを適用した状態で静的成果物のRSSとllms.txtを確認し、掲載先HTML・Markdownとヘッダー導線が一致する。

## 対象外

- 翻訳コンテンツ作成
- 日英ペア強制と本文リンク検査
- 新しいサイトマップ機能、外部サイトの到達確認

## 品質境界

既存の日本語購読・Markdown案内を壊さず、実在する英語記事だけを案内する。本文翻訳の品質は本Issueで判定しない。

## 実装メモ

RSS・llms.txt・共通ヘッダーを対象にする。言語別URL生成と記事選択はBLOG-021の仕組みを使う。単独配備の前提はBLOG-021であり、全記事の翻訳は必須でない。ロールバック時は英語RSSへの導線も同時に戻す。

- このJP/EN対応では、一時的な `develop` を統合先とする。Issueブランチは最新の `develop` から作成し、Issue IDを含める。各Issueは承認後にclosedの記録を含めて `develop` へ `--no-ff` で統合する。通常運用のmain向け統合規則に対する、今回のユーザー承認済み例外である。
- mainでは日本語記事の執筆・公開を続ける。必要時および最終統合前にmainをdevelopへ取り込み、記事を失わない。Issueの完了はdevelopへの統合を意味し、本番配備済みとは扱わない。
- BLOG-021〜BLOG-024がすべてclosedとなり、最新mainを取り込んだ全記事の日英対応とビルドを再確認してから、人間の明示承認を得てdevelopをmainへ `--no-ff` で統合する。承認済みなのは今回の起案内容のmainへの直接コミットまでで、将来の統合・push承認を含まない。
- 本Issueは依存と記載の前提が満たされれば後続Issueなしでビルド・配備できる状態にする。実際の本番公開は全Issue完了後とし、main向けの既存配備workflowは維持する。

# 記事のRSSフィードを公開する

## 問題

サイトには記事の一覧とページ送りがあるが、新しい記事の公開を継続的に受け取るためのRSSフィードがない。

## 意図

記事のタイトル、概要、公開日時を含むRSSフィードを静的に公開し、読者が更新を購読できるようにする。

## 受け入れ条件

- [ ] `/rss.xml` から有効なRSSフィードを取得できる。
- [ ] フィードにサイト情報と、公開中の全記事のタイトル、記事URL、概要、公開日時が含まれる。
- [ ] 記事は公開日時の新しい順に並び、ページ送りの有無にかかわらず各記事が一度ずつ含まれる。
- [ ] 記事URLはサイトの正規の絶対URLを指し、XMLの予約文字を含む値も正しく読める。
- [ ] サイトのページからフィードを発見でき、記事がない場合もフィードが有効な形で出力される。
- [ ] 記事の追加・更新に伴ってフィードが自動更新され、別の手動リストを保守しない。

## 対象外

- RSS本文への記事全文掲載
- メール通知、購読者管理、外部配信サービス
- Atomなど別形式のフィード

## 品質境界

静的ビルド時点で公開中の記事とメタデータが正しくフィードへ反映され、読者が標準的なRSSリーダーから購読できることを対象とする。記事本文のHTML変換や購読者データの管理は含めない。

## 実装メモ

- `title`、`description`、`publishedAt` は既存の必須メタデータを使える。
- サイトの絶対URLは `astro.config.mjs` の `site` 設定を基準にする。
- 概要のみを配信し、フィードの各記事URLは既存のHTML記事ページを指す。

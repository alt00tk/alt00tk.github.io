# 英語記事の翻訳注釈を記事から独立させる

## 問題

英語記事の翻訳注釈が記事ヘッダーの後に通常の段落として表示され、本文の書き出しに見える。原文リンクには既存の本文リンク装飾が適用されていない。

## 意図

英語記事共通の翻訳注釈を最初に気付ける独立した案内として表示する。

## 受け入れ条件

- [x] 英語記事のサイトヘッダー直下、記事タイトルより前かつarticleの外側に、見出しなしの注釈帯を共通表示する。
- [x] 既存の注釈文と対応する日本語記事へのリンクを維持し、リンクは本文と同じアクセント色・破線の下線にする。
- [x] 注釈帯とページヘッダーの間隔は通常幅24px・640px以下18px、記事日付との間隔は20pxとし、変更前の半分にする。
- [x] 罫線を追加せず、薄い背景色、内側の余白、記事との間隔で区別する。
- [x] 日本語記事・一覧には表示せず、ライト・ダークテーマと320px幅で可読性と横あふれのない表示を確認する。
- [x] ビルド、独立レビューを実施してコミットする。

## 対象外

- 注釈文の変更、記事翻訳の修正
- main/developへのマージ、push、本番配備

## 品質境界

既存の記事本文、日英切替、原文リンクを維持する。注釈帯は英語記事だけに表示し、既存の区切り線は増やさない。

## 実装メモ

本セッションのユーザー指示によりdevelopを起点とし、統合先もdevelopとする。コミットまで承認済み。マージは別途承認が必要。

## 設計判断

- 注釈を共通ArticlePageのmain直下、articleより前のaria-labelで名前を付けたasideへ移した。英語記事共通の補足案内として本文から構造的にも分離し、最初に読める順序にするため。
- 背景は既存テーマの文字色を5%混ぜ、罫線は追加しない。本文より小さい1remの文字と内側の余白を使い、記事まで20pxの間隔を設けた。
- 原文リンクは本文リンクと同じCSS規則を共有する。注釈をarticle-contentへ入れて装飾を得る案は、本文から分離する目的に合わないため採用しない。

## レビュー指摘

- ユーザーの表示確認により見出しを削除し、ヘッダー・日付との余白を半分へ調整。追加差分の独立レビューもLooks acceptable、指摘なし。asideの名前はaria-labelで維持した。

- 独立エージェントによるreview-orchestratorレビュー: Looks acceptable。Blocking/Warning/Noteはいずれも0。構造・境界、実装整合性、セキュリティ、テスト整合性、保守性とアクセシビリティ・テーマ・狭幅を確認し、指摘なし。レビュー側のブラウザ未実施という制約は実装担当側のChromium検証で補った。

## 完了記録

- 変更: 英語記事の翻訳注釈をarticle外の注釈帯へ移動。見出しを省いた薄い背景、内側の余白と記事との間隔を追加。原文リンクを既存のアクセント色・破線の下線に統一。
- 検証: npm run build成功。Chromiumで1000/375/320pxとlight/darkの6組を確認。注釈のDOM・表示順、罫線なし、背景色の区別、本文リンクとの色・破線・太さの一致、原文URL、横あふれなし、日本語記事・日英一覧で非表示を検証。1000pxライトと320pxダークのスクリーンショットを目視確認。検証用スクリプトと画像は/tmpに置き、リポジトリには追加しない。git diff --check成功。
- 追加検証: 見出し削除と余白調整後にビルド成功。Chromiumで1000/375/320px・light/darkの6組を再確認し、見出しなし、ヘッダーとの間隔24px（640px以下18px）、日付との間隔20pxを実測。既存のリンク・罫線なし・横あふれなし・日本語記事と一覧の非表示も確認。
- 統合状態: ユーザーからdevelopへのマージ承認を取得。closedの記録を含めてdevelopへ --no-ff で統合する。mainへの統合・push・本番配備は対象外。

# サイト全体の文字サイズを1.25倍にする

## 問題

記事執筆中のローカルプレビューで、現在の一覧と記事ページの文字サイズを大きくして読みやすさを確認した。
現行の文字サイズより1.25倍の表示を正式なデザインへ反映する必要がある。

## 意図

サイト全体の文字サイズを現在の1.25倍にし、確認済みのローカルプレビューと同じ表示を維持する。

## 受け入れ条件

- [x] 一覧、記事詳細、ページ送り、ヘッダー、フッターの文字サイズが従来値の1.25倍になる。
- [x] 記事タイトルの可変サイズと640px以下の指定も1.25倍になり、本文内のコード文字は親要素に合わせて拡大される。
- [x] 文字サイズ以外のCSS、記事データ、ページ構造を変更せず、ローカルプレビューで承認された表示を再現する。

## 対象外

- 記事内容の追加・編集と、幅・余白・色・行高の再調整
- デプロイ設定やページ機能の変更

## 品質境界

BLOG-004で実装した一覧・詳細・ページ送りのデザインを保ち、既存の文字サイズ指定だけを1.25倍へ更新する。執筆中の記事とその他の未コミット変更を統合対象へ含めない。

## 実装メモ

- ユーザーはローカルプレビューで変更を確認し、正式なIssue化とmainへのマージを依頼した。
- 現在のmain作業ツリーには執筆中の記事など未コミット変更があるため、専用worktreeで統合する。

## 設計判断

- 既存の各`font-size`値を1.25倍にした。ルートの文字サイズを変更すると、文字以外の`rem`指定の余白も変わるため採用しなかった。本文内コードの`0.9em`は親要素の拡大に追従するので維持した。

## レビュー指摘

- 指摘なし。CSS差分の全変更が文字サイズ指定に限定され、各値と可変幅の`vw`値が1.25倍であることを確認した。

## 完了記録

- 変更: `src/styles/global.css`の文字サイズ指定12箇所を1.25倍にした。記事やページ構造は変更していない。
- 検証: ユーザーが執筆中の記事を使ったローカルプレビューで表示を承認した。`git diff --check`に問題はなく、CSS差分は文字サイズ指定のみであることを確認した。
- レビュー観点: 一覧と詳細の本文・見出し・日付、ページ送り、フッター、小画面のタイトル指定が同じ倍率で拡大されているか確認する。

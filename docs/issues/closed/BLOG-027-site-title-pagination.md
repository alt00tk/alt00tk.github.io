# サイト名と一覧の表示件数を調整する

## 問題

サイト名が notes、一覧が1ページ10件となっており、希望する表記と件数に合っていない。

## 意図

サイトの基本表示を希望する名前と一覧密度に揃える。

## 受け入れ条件

- [x] 日英のヘッダー、文書タイトル、記事タイトルの接尾辞、フッター、OGP、RSS、llms.txtのサイト名が alt00tk's notes になる。
- [x] 日英の記事一覧が1ページ最大8件となり、ページ間で記事の欠落・重複がない。
- [x] ビルドと生成結果の確認が成功する。

## 対象外

- 記事本文、OGP画像、検索や保存済み設定の仕様変更。

## 品質境界

既存の共通表示とページ分割の設定変更に限定する。日英の生成HTMLとページ間の記事の連続性を確認する。

## 実装メモ

alt00tk's notes は所有格として自然な英語表記。OGP画像の代替文は画像内容の説明なので変更しない。

## 設計判断

## レビュー指摘

- 指摘なし。日英の共通表示、文書タイトル、OGP、RSS、llms.txtの変更箇所とページ分割を確認した。画像の説明文と保存キーは表示名ではないため維持した。

## 完了記録

- 変更: サイト名を alt00tk's notes に統一し、共通ページ分割を10件から8件へ変更した。既存RSS検証の期待値も更新した。
- 検証: npm run build、git diff --check成功。生成HTMLの解析で日英とも8件・6件の2ページとなり、記事の欠落・重複がないことを確認。全HTMLの文書タイトル、日英RSSタイトル、llms.txt見出しを確認した。
- レビュー観点: 日英の表示名と共通ページ分割。mainへのマージ・pushはユーザー承諾済み。

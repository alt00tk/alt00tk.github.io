# 記事内のMarkdown表を既存テーマに調和させる

## 問題

Markdown表はHTMLへ変換されるが、記事内の表には専用のスタイルがない。
セルの余白、罫線、狭い画面での表示が整備されていない。

## 意図

記事内の表をライト／ダーク両方の配色と本文の読みやすさに調和させる。

## 受け入れ条件

- [x] ライト／ダーク／システム設定で既存テーマに追従した控えめな罫線と見出し行になる。
- [x] セル内と表の前後に余白があり、Markdownの左・中央・右寄せが保持される。
- [x] スマートフォンで幅の広い表を表内で横スクロールでき、ページ全体を横にはみ出させない。
- [x] 表の見出しとデータの意味構造を保持する。
- [x] ビルドと実ブラウザでの配色・配置・横スクロール確認が成功する。

## 対象外

- 記事本文の変更、表の並べ替え、縞模様やホバー効果。

## 品質境界

日英共通の記事本文にある通常のMarkdown表を対象とする。
既存のテーマ変数を利用し、狭い画面での閲覧と表の意味構造を守る。

## 実装メモ

既存記事に表がないため、検証用のMarkdown表で表示を確認する。

## 設計判断

- 決定: 記事本文に限定したCSSで表自体を横スクロール領域とし、既存のテーマ変数から罫線と見出し背景を生成する。
- 理由・根拠: 通常のMarkdown出力に追加処理を必要とせず、Chromiumで表と列見出しの意味構造および配置指定が保持されることを確認した。
- 却下した選択肢: スクロール用ラッパーをHTML生成処理へ追加する案は、今回の表示要件をCSSだけで満たせるため採用しない。
